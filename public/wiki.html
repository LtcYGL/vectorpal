三件事，先确认

  1. 控制台起着：页头左边那个绿点写着「在线」。
  2. 机器人在线：页头第二个绿点写着「机器人在线」。它要是关机或者在重启，这里是灰的 —— 等它自己回来，不要反复点。
  3. 把它从充电仓上抱下来：站在仓上时，固件会忽略一切外部马达指令（引擎日志里那句 external motor commands are not allowed），动画、抬头、走路全都不动，只有说话和换眼睛能用。

先玩这三个

  • 「玩 · 说 · 动作」页 → 打个招呼；
  • 动作库里搜 greeting，挑一个点一下；
  • 「编程工坊」→ 拖两块积木 → 运行。

一句话：能精确控制的只有「轮子、头、升降、眼睛、动画、声音流」这六样，其余的高层行为得靠 AppIntent 借固件自己的动作库。

清单来自机器人自己身上的 anim_manifest.json，一共 1208 个名字，每个都带时长。动画就是一段预设的关节轨迹 + 表情 + 音效，播完自己结束。

名字的规律

  • anim_greeting_* 打招呼、anim_dance* 跳舞、anim_blackjack_* 21 点牌局
  • anim_rtmotion_* / anim_rtsound_* 被摸到、听到声音的反应
  • anim_communication_* 表达类（点头、摇头、cantdothat）
  • anim_explorer_* 四处看、anim_loco_* 走路的起停动作

为什么有时候点了没反应

  1. 没接管控制：它正在自主动作时，动画请求会被引擎直接丢掉（日志里连请求都不出现）。本程序已经自动先接管，点之前不用管。
  2. 名字不存在：引擎日志会写 AnimationComponent.PlayAnimByName.AnimNotFound。
  3. 站在充电仓上：所有马达指令被忽略。
正在读动画清单…

触发器不是单个动画，而是一组动画的入口：固件按当时的情绪、朝向自己挑一段播。比如 BlackJack_Deal 会走「发牌」那一整套。

不是每个触发器在这台机器上都有映射；没有映射的会落成 anim_communication_cantdothat_0x（就是那个「摇头说不行」）。试一下就知道。

正在读触发器清单…

控制台自己就是一层 HTTP API，跑在 http://<本机IP>:8090。局域网访问要带 PIN（设置页能看到），本机访问不用。下面每一行都可以直接点「试」。

写程序的四个坑

  1. 一定要从充电仓下来，否则除了说话全都不动。
  2. 别指望它回到起点：轮子打滑就偏了，导航不可靠；要定位就拍张照看。
  3. 长程序要能停：「停下」按钮会把当前这一步也掐掉。
  4. 说话和动画别叠着来：声音会被动画音效盖住，先说完再动。

它怎么听见你

麦克风 → 固件判断唤醒（Hey Vector 或按键）→ 录 6 秒 → OGG_OPUS 16k
      → 控制台 chipper.StreamingIntentGraph → 本地 STT（sherpa-onnx 中文）
      → 匹配你写的触发词 → 执行积木步骤 → 本机合成语音推回去

唤醒的两种方式

  • 说「Hey Vector」：固件写死的，改不了。麦克风老化时很难喊醒。
  • 按头顶的按钮：设置页勾上「按键唤醒」就写到机器人身上了（button_wakeword=1），掉电也不会丢。

为什么有时候听不准

  • 只有 6 秒窗口，说长了后面被截断；
  • 模型是 14M 的流式中文模型，离得远、有电视声就容易听成别的字（实测「你好」被听成过「利」）；
  • 建议 30 厘米内、慢一点、一次说一件事。

关于那个「网络叹号」

那是固件自带的 anim_nocloud_icon_01，意思是「云端没给我答复」。我们这套链路里它出现在唤醒之后云端没回话的那一瞬，不影响后面的动作执行；如果你看到它并且动作也没做，先看设置页的 pod 日志里有没有 StreamingIntentGraph 记录。

加一条自己的口令

「玩 · 说 · 动作」页 → 语音助手 → 写一句孩子会说的话 + 选一个动作 → 添加。加完在「试一句」里输入同样的字就能验证匹配，不用喊。

页面上的话真正的原因怎么办
它现在站在充电仓上，固件会忽略所有外部动作指令…在仓上时马达被锁抱下来，或点「让它下充电仓」
它正在忙上一个动作，等一两秒再点动作互斥，上一件事还没结束等它做完；急就点急停
机器人没反应（可能关机了或在重启），等它连上再试3 秒内事件流没更新看页头徽章；它自己会重连
没做成：BehaviorControl: no grant response没抢到行为控制（自主动作占着）再点一次，程序会自动重试
引擎日志 AnimNotFound动画名不在 manifest 里在动作库里搜正确的名字
引擎日志 InvalidAnimTrigger触发器在这台机器上没有映射换个触发器，或直接用动画
401 / 要 PIN局域网访问控制台输入设置页里那个 6 位 PIN
ERR 3 Invalid Action tag_id用了带动作标签的旧接口（GoToPose 等）改用轮子/头/升降自己闭环
  • 电池已经老化：连续跑动作十几分钟就可能掉电停机，测试时尽量插着充电线。
  • 只能有一条 SDK 会话：控制台连着的时候，另开脚本连它会得到 401。要外部调试就走 /api/robot/rpc。
  • 精度：前进/后退 ±2%，转向 90° ±0.8%（陀螺仪闭环 + 0.28 秒刹车提前量）。
  • 回仓不可靠：试过 120 秒没成功，坐标还会突然归零 —— 需要充电就手动放上去。
  • 它的时钟和时区写在它自己身上（设置页改），掉电不丢。
  • 机器人在 192.168.1.254，控制台在 192.168.1.21，两个 DHCP 保留地址，重启路由器后可能会变。
